# Health-Bridge
Real-time health resource mapping and event tracking.
---

## The Problem

Healthcare information is often fragmented, making it difficult for communities to locate active health camps and essential services in real-time.

---
## Problem statement

Bridging health care gaps with real time connectivity

---
## The Solution

HealthBridge provides an interactive, map-based dashboard that connects users to local health initiatives.

It is designed to be *highly scalable*, allowing it to expand from a single community to a city-wide or regional network effortlessly.
## Tech Stack

### Backend
- Flask (Python)

### Maps
- Leaflet.js

### Frontend
- HTML5
- CSS3

### Deployment
- Render
